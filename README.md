# CashUp – אתר ציבורי (בלי שרת)

כל התיקייה הזו היא אתר סטטי. אין שרת, אין מסד נתונים ואין הרשמה – כל משתמש שומר את הנתונים שלו בדפדפן שלו.

## מה יש כאן
| קובץ | מה זה |
|---|---|
| `index.html` | דף נחיתה שיווקי |
| `app.html` | האפליקציה עצמה |
| `privacy.html`, `terms.html` | טיוטות מדיניות פרטיות ותנאי שימוש – **למלא את מה שבסוגריים [ ]** |
| `manifest.webmanifest`, `sw.js`, `img/` | התקנה למסך הבית ועבודה גם בלי אינטרנט |

## איך מעלים לאוויר (בחינם)
צריך אחסון שמגיש קבצים ב-HTTPS. שלוש אפשרויות פשוטות:

1. **Netlify Drop** – נכנסים ל-app.netlify.com/drop, מתחברים, וגוררים את התיקייה `public` לחלון. מקבלים כתובת תוך דקה.
2. **Cloudflare Pages** – יוצרים פרויקט חדש ← "Upload assets" ← מעלים את התיקייה.
3. **GitHub Pages** – יוצרים מאגר, מעלים את הקבצים, ובהגדרות ← Pages בוחרים את הענף הראשי.

אחר כך אפשר לחבר דומיין משלכם (למשל cashup.co.il) מתוך הגדרות האחסון.

## לפני ההשקה
- למלא בדפי הפרטיות והתנאים: תאריך, שם ספק האחסון, מייל ליצירת קשר.
- לא להוסיף כלי אנליטיקה/פיקסלים בלי לעדכן את מדיניות הפרטיות.
- כל שינוי באפליקציה: לבנות מחדש ולהעלות שוב את התיקייה (ה-service worker יתעדכן לבד).
